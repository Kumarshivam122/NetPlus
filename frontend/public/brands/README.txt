BRAND LOGOS
===========
One image per brand, cropped from the logo sheet you supplied.

To change a logo: replace the file here with the new one using the SAME file name,
or point the brand at the new file in src/data/store.js (BRANDS -> logo).
To add a brand: add the image here and add one line to BRANDS in src/data/store.js.

Tips: transparent or white background, roughly 3:1 to 1:1 shape, at least 300 px wide
so the logo stays sharp on high-resolution screens.
